Drop headband plate / village emblem atlas textures here (png / jpg / webp).

Each image contains BOTH plate conditions in one 512x512 atlas:
- LEFT half: scratched emblem
- RIGHT half: clean emblem

The Character Creator and NPC Inspector have a Plate Condition selector that switches the plate UVs
between those two halves. Do not make separate scratched and clean copies of the same village symbol.

The file name is the village/symbol label:
"suna_plate.png" -> "Suna Plate". "Default texture" uses the atlas embedded in character_main.glb.

These are plate/emblem textures only. The cloth part of the headband is colour-controlled separately.
